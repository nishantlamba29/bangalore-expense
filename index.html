Easy Hosting & Google Sheets Guide

Step 1: Open sheets.new to create a new blank Google Sheet.

Step 2: In the menu, click Extensions → Apps Script.

Step 3: Delete all existing code in the editor, paste the following code snippet, and click Save ():

function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(["ID", "Date", "Category", "Amount (INR)", "Payment Method", "Description"]);
    }
    var data = JSON.parse(e.postData.contents);
    sheet.appendRow([data.id, data.date, data.category, data.amount, data.paymentMethod, data.description]);
    return ContentService.createTextOutput(JSON.stringify({"result": "success"})).setMimeType(ContentService.MimeType.JSON);
  } catch(error) {
    return ContentService.createTextOutput(JSON.stringify({"result": "error", "message": error.toString()})).setMimeType(ContentService.MimeType.JSON);
  }
}

Step 4: Click Deploy → New deployment.

Step 5: Select type → Web app. Set Who has access to "Anyone". Click Deploy & copy the Web App URL into this app's sync setup!

How to host this app for free so you can use it on your phone:

Option A: GitHub Pages (Recommended)

1. Create a free repository on GitHub named namma-spends.

2. Save this HTML file as index.html and upload it to the repo.

3. Go to Repo Settings → Pages → Select main branch → Save. Access your live web app URL on your phone browser!

Option B: Vercel / Netlify Drag & Drop

1. Go to Netlify Drop or Vercel.

2. Put index.html inside a folder and drag-and-drop the folder onto Netlify. Your app goes live in 5 seconds!

Mobile Tip: Open your deployed link on Chrome/Safari on your mobile phone, tap "Add to Home Screen" to use it just like a native app!
